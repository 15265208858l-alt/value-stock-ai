# A股价值研投

ValueStock AI：AI驱动的A股长期价值投资研究平台。

**定位：用AI研究价值，而不是追逐情绪。**

## 核心研究能力

围绕长期价值投资建立完整研究链路：

- 企业质量与5年财务质量
- 经营现金流与风险排查
- 正常化EPS / TTM EPS
- 行业自适应估值
- 历史PE估值
- 同行业比较
- 安全边际
- 综合投资价值评分
- 最终投资决策

## 产品状态

**核心研究引擎已冻结（2026-09-02）。**

冻结范围包括数据获取与缓存、财务分析、风险检查、正常化EPS/TTM EPS、行业自适应估值、历史PE、同行比较、综合评分与最终决策。商业化阶段原则上不再修改上述计算链路，除非发现数据错误、计算错误、严重性能问题或系统崩溃。

## 商业化路线

当前进入商业化层建设：

1. 免费研究 + 专业会员能力层
2. 用户登录与会员身份
3. 个人股票池
4. 估值/价格提醒
5. 深度历史估值与多股票比较
6. 一键生成标准化研究报告
7. 内容平台获客与会员转化

### 免费版规则

- 免费版只允许完整测试 **1 只不同股票**。
- 同一只已经测试过的股票可以重复查看，不重复消耗试用名额。
- 免费版不开放同行多股票扩展研究。
- 专业会员后续提供不限股票研究及持续跟踪能力。

当前试用控制属于产品原型阶段的**会话级限制**，不是最终商业级安全鉴权。正式收费前必须接入服务端账号、数据库、支付回调、服务端权限校验、防刷与异常访问监控。

会员权限层已经独立为 `membership.py`，试用控制位于 `commercial_guard.py`，均不参与核心研究计算。

详细规划见 `MONETIZATION_ROADMAP.md`，安全基线见 `COMMERCIAL_SECURITY_BASELINE.md`。
