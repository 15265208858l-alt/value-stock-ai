# A股价值研投

ValueStock AI：AI驱动的A股长期价值投资研究平台。

**定位：用AI研究价值，而不是追逐情绪。**

## 核心研究能力

围绕长期价值投资建立完整研究链路：

- 企业质量与5年财务质量
- 经营现金流与风险排查
- 正常化EPS / TTM EPS
- 行业自适应估值
- 历史PE估值
- 同行业比较
- 安全边际
- 综合投资价值评分
- 最终投资决策

## 产品状态

**核心研究引擎已冻结（2026-09-02）。**

冻结范围包括数据获取与缓存、财务分析、风险检查、正常化EPS/TTM EPS、行业自适应估值、历史PE、同行比较、综合评分与最终决策。商业化阶段原则上不再修改上述计算链路，除非发现数据错误、计算错误、严重性能问题或系统崩溃。

## 商业化路线

当前进入商业化层建设：

1. 免费研究 + 专业会员能力层
2. 用户登录与会员身份
3. 个人股票池
4. 估值/价格提醒
5. 深度历史估值与多股票比较
6. 一键生成标准化研究报告
7. 内容平台获客与会员转化

会员权限层已经独立为 `membership.py`，默认用户仍为免费用户，不要求登录即可运行核心研究。

详细规划见 `MONETIZATION_ROADMAP.md`。
