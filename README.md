# A股价值研投

**ValueStock AI**：AI驱动的A股长期价值投资研究平台。

> 用AI研究价值，而不是追逐情绪。

## 产品定位

从企业基本面、现金流、正常化EPS、行业自适应估值、历史估值、同行比较、安全边际和综合评分等维度，辅助投资者进行长期价值研究。

## 稳定性

项目已加入 GitHub Actions Python 语法冒烟测试：每次推送或提交 Pull Request 到 `main` 时，自动执行 `python -m compileall`，在部署前尽早发现语法错误。

## 免责声明

本项目用于信息整理与投资研究辅助，不构成任何证券投资建议、收益承诺或个性化投资推荐。市场有风险，投资需独立判断。
