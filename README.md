# A股价值研投｜ValueStock AI

ValueStock AI 是面向 A 股长期价值投资的研究平台，目标是把财务质量、现金流、估值、安全边际与风险排查整合成可复核的研究流程。

**产品原则：用数据研究价值，不追逐情绪；区分财务事实、规则判断与需要人工核查的事项。**

## 当前功能

主应用 `app.py` 已集成以下研究模块：

- 企业财务质量：ROE、营收与净利润增长、资产负债率及历史趋势
- 三大报表与财务排雷：经营现金流、应收账款、存货及相关风险提示
- 自由现金流分析：经营现金流、资本开支、自由现金流及风险闸门
- 公司治理与股东结构：在可获取数据范围内进行结构化检查
- 行业自适应估值：正常化 EPS、PE/PB 情景估值、安全边际
- 历史估值：历史 PE 统计与估值分位
- 同行比较：独立主应用通过 `peer_compare.py` 进行同行数据比较；结果取决于同行数据是否成功获取
- 综合投资评分与最终决策：同时展示研究可信度、风险等级和建议操作
- V18 长期价值投资 10 步检查
- V19 财务趋势分析
- V20 价值投资雷达（解释层，不替代核心计算）
- V21 一键专业研究报告，可在页面查看并下载 Markdown 文件
- 个人股票池、研究快照与会员界面（具体能力取决于当前配置）

## 版本与核心引擎说明

主应用目前包含 V18 十步分析、V19 财务趋势、V20 价值投资雷达和 V21 专业研究报告等功能层。

`analysis_engine.py` 是供其他工作流复用的共享分析引擎，当前文件标注为 V17.2.2。为减少额外数据请求，该共享引擎目前**不执行同行业比较**，其 `peer.score` 为 `None`；这不等同于主应用 `app.py` 的同行比较模块被关闭。

核心研究计算链路于 2026-09-02 冻结。除非发现可复现的数据错误、计算错误、严重性能问题或系统崩溃，后续优先改进诊断、展示、测试和文档，不随意调整估值公式与评分规则。

## 运行方式

建议使用 Python 3.10 或更新的兼容版本。

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 稳定性检查

仓库包含 GitHub Actions 的 Python 语法/导入烟囱测试。该测试有助于发现部分基础问题，但**不能替代真实股票数据的端到端验收**。发布前建议至少验证：

1. 000333 美的集团：财务数据、估值、同行比较、十步分析与 V21 报告
2. 300308 中际旭创：成长型企业估值及数据完整性
3. 000938 紫光股份：财务趋势与同行比较
4. 601318 中国平安：金融企业指标适配性

如任一关键字段显示“暂无”，应先区分“源数据缺失”“字段映射不匹配”“计算未执行”和“界面未展示”，再决定是否修改代码。

## 商业化状态与安全边界

当前免费试用控制属于产品原型：会话级限制不是正式商业级安全鉴权。正式收费前必须完成服务端账号身份验证、数据库持久化、服务端权限校验、支付回调验签、订单状态核验、防刷与异常访问监控。

会员权限与核心研究计算保持解耦。不要仅凭前端显示或客户端状态授予付费权限。

商业化路线包括个人股票池、估值提醒、深度历史估值、多股票比较、标准化研究报告与会员能力层。支付功能在完成端到端测试前，不应宣传为已正式可用。
